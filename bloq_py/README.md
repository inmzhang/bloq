# bloq-py

Python bindings and CLI for [Bloq](https://github.com/inmzhang/bloq), a compiler for
surface code spacetime layouts.
Requires Python 3.10 or later; install with `pip install bloq-py` and use
`import bloq` or the `bloq` command.
See the [Python API](https://bloqec.com/docs/dev/api/python.html) and
[installation guide](https://bloqec.com/docs/dev/getting-started/installation.html)
for usage and development setup.
