Struct PauliString 

Source 
pub struct PauliString { /* private fields */ }
Expand description

A dense unsigned Pauli operator over len qubits, stored as XZ bit vectors.

Phaseless, with each site read as the Hermitian single-qubit Pauli it names — a site carrying both bits is Y = iXZ, not the bare product XZ. A product of Hermitian factors on distinct sites is Hermitian, so every PauliString is a valid measurement observable or rotation axis by construction; there is no phase to make it otherwise. Operations between different widths treat missing trailing sites as identities; XOR keeps the wider width. Parse strings of I, _, X, Y, and Z with str::parse; Display renders identity as _.

pub fn from_terms( num_qubits: usize, terms: impl IntoIterator<Item = (usize, Pauli)>, ) -> Self

Collects (index, pauli) terms into a string over num_qubits qubits.

Terms are assignments, not factors: a repeated index keeps the last Pauli given for it rather than multiplying the two.

§Panics

Panics if any index is >= num_qubits.

let stabilizer = PauliString::from_terms(3, [(0, Pauli::Z), (2, Pauli::Z)]);
assert_eq!(stabilizer.to_string(), "Z_Z");

pub fn commutes_with(&self, other: &Self) -> bool

Returns true if self and other commute as operators.

Two Pauli strings anticommute exactly when they anticommute on an odd number of sites, which the symplectic form ⟨x, other.z⟩ + ⟨z, other.x⟩ counts mod 2.

The two strings need not name the same number of qubits. Where one runs out the other is being compared against implicit identities, which commute with everything — so the fold below stops at the shorter operand rather than requiring equal widths. Going through the words directly is also what avoids BitVec::dot, whose length assertion holds in release builds and would turn a width mismatch into a panic.

§Examples
use bloq_utils::PauliString;

let xx = PauliString::try_from("XX")?;
let zz = PauliString::try_from("ZZ")?;
let zi = PauliString::try_from("Z_")?;
assert!(xx.commutes_with(&zz));   // two anticommuting sites
assert!(!xx.commutes_with(&zi));  // one

// Widths may differ; the shorter string ends in implicit identities.
let x_wide = PauliString::try_from("X___")?;
assert!(!x_wide.commutes_with(&PauliString::try_from("Z")?));
assert!(x_wide.commutes_with(&PauliString::try_from("_Z")?));

pub fn x_words(&self) -> &[u64]

The X components as u64 words, least-significant qubit first.

Word-level access for bit algebra over whole strings — the simulator’s frame decomposition walks these directly rather than one site at a time. Bits at or beyond len are always clear.
