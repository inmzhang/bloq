Expand description

Eliminate one linear constraint pointwise, returning its conditional pivot.

The first available pivot is selected by disjoint guards, so no assignment enumeration or product of alternative row spaces is needed.

§Errors

Returns BooleanResourceError if elimination exceeds configured limits.
