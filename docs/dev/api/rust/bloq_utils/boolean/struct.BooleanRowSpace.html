Struct BooleanRowSpace 

Source 
pub struct BooleanRowSpace { /* private fields */ }
Expand description

A sparse conditional row space with stable source order and column incidence.

Row slots stay fixed while pivots remove rows. Default methods visit only possible contributors in source order; explicit sparse variants prefer shorter rows when individual representatives may change.
