Enum Pauli 

Source 
#[repr(u8)]
pub enum Pauli {
    I = 0,
    X = 1,
    Z = 2,
    Y = 3,
}
Expand description

A single-qubit Pauli operator.

The discriminants are the XZ symplectic encoding (X sets bit 0, Z sets bit 1), so the bit algebra in BitOr/BitXor/BitAnd and PauliString depends on these exact values. Keep them fixed.
