Struct RGBA

pub struct RGBA {
    pub r: u8,
    pub g: u8,
    pub b: u8,
    pub a: u8,
}
Expand description

An 8-bit-per-channel RGBA color.

Every channel is 0..=255; a is opacity, with 255 fully opaque.

Fields§
