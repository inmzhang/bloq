Expand description

Structural counts across every graph level, including guarded and RUS bodies.

These describe stored IR without inspecting physical circuit payloads, expanding fixed repeats, selecting guards, or multiplying RUS attempts.

Fields§

§template_count: usize

Templates in the compiled pool, including unreferenced templates.

§node_count: usize

Nodes across all graph levels, including region containers.

§edge_count: usize

Edges across all graph levels.

§node_counts: BTreeMap<&'static str, usize>

Node counts by concrete variant name, including zero-count types.

§edge_counts: BTreeMap<&'static str, usize>

Edge counts by concrete variant, including zero-count types.

§is_static: bool

Whether execution structure is fixed: no regions, activation, guarded membership/seams, or shot discard. Ordinary classical readout/decoder computation and fixed circuit repeats do not make structure dynamic. This does not certify validity or backend emittability.
