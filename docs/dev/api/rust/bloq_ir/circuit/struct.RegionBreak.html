Expand description

A recorded anticommutation: the region could not continue past this point.

Fields§

§detector: u32

Region that stopped propagating.

§segment: usize

Segment whose undo revealed the break.

§qubit: IVec2

Qubit where anticommutation occurred.

§kind: RegionBreakKind

Cause of the break.
