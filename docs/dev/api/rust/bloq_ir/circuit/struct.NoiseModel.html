Expand description

Circuit-level Pauli noise probabilities materialized by NoiseModel::noisy_circuit.

Fields§

§p1: f64

Single-qubit depolarizing probability after each noisy 1q gate.

§p2: f64

Two-qubit depolarizing probability after each 2q gate.

§p_meas: f64

Measurement result-flip probability.

§p_reset: f64

Orthogonal-state preparation probability after each reset.

§p_idle: f64

Per-tick single-qubit depolarizing probability on idle footprint qubits.

Whether idle noise needs repeat expansion to account for moments that cross a repeat boundary. Annotation owners must flatten their side tables together with the circuit before applying noise in this case.

§Errors

Source

pub fn noisy_circuit_excluding( &self, circuit: &CoordCircuit, ideal_qubits: &[IVec2], ) -> Result<CoordCircuit, CircuitError>

Self::noisy_circuit while keeping ideal_qubits free of generated or pre-existing error channels. A two-qubit channel is removed when either member of its pair is ideal. Repeats sharing a moment with their surroundings are flattened; final measurement ids are retained.

§Errors

Returns the circuit’s flatten error if a repeat needing expansion is invalid, exhausts measurement ids, or exceeds the expansion allowance. Returns CircuitError::BodyIdOutOfRange if a body index exceeds u32::MAX.
