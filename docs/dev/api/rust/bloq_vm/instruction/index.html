Module instruction 

Source
Expand description

Backend-independent instructions executed by the Bloq VM.

The types in this module deliberately contain no Bloq IR node, graph, or expression types. crate::lower() resolves those into dense identifiers, executable quantum streams, and structured control flow once up front.
