Expand description

Failures on the noiseless physical-verification path.

That path is the run_bloq family, CircuitExecutor, and the shared program-preparation and output-closure analysis in front of them — which lower() also runs, and reports as LowerError::Analysis.

The dynamic causal runtime is the other execution engine in this crate and reports RuntimeError instead. Neither type is a superset of the other: this one covers exact execution and the static analysis in front of it, RuntimeError covers timing, retries, and mock decoding.

MalformedGraph(&'static str)

§

DecodeObservableNotClosed

A Decode’s named observable folds an Output-face boundary operator whose support a quantum node scheduled AFTER the decode’s cut touches: the operator has no unresolved-but-modeled frontier, so the decoder estimate computed at the cut would refer to a face the later node reopens/consumes — a wrong-time boundary. Unlike the terminal read, which closure::plan_early_output_reads moves in front of the consuming node, a decode cut has no fixture and stays rejected up front by guard_decode_observable_closure. observable is the Observable node id, decode/later are node ids, instance the boundary operator’s instance.

Fields

§decode: u32

Decode node reading the observable.

§observable: u32

Observable node being read.

§instance: u32

Boundary-owning template instance.

§later: u32

Later node touching the boundary.

§

IncompatibleEarlyOutputReads

Incompatible partial observable reads cannot be split across output cuts without destroying their joint correlations.

Fields

§first: u32

First incompatible observable.

§second: u32

Second incompatible observable.

§before: u32

Node before which both reads are required.

§

EarlyOutputGateUnavailable

An exported boundary’s condition is unavailable before its output is consumed.

Fields

§observable: u32

Observable whose gate is unavailable.

§before: u32

Node requiring the early read.

§
