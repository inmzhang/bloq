Expand description

Run run_bloq_with_hook while preserving reused output patches.

Each reused patch is swapped onto a private ancilla at its output cut. The hook reads those ancillas through ShotContext::saved_outputs, allowing a joint-state oracle to include outputs no longer live at program termination.

As with any mutating hook, only the record-based detector portion of the returned report remains meaningful.

§Errors

See ExecError; also propagates any error the hook returns.
