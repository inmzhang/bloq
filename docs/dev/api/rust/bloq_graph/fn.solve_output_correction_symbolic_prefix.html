Expand description

Solve the full joint system, materializing at most its first output_count outputs. All constraints and runtime consistency checks remain active.

Pivot order and the free-variable policy are identical to solve_output_correction_symbolic. A module linker can put public outputs first and retain internal seam variables without expanding their frames.

§Errors

Returns OutputCorrectionError::UnknownOutput if a row names an absent output.

§Panics

Panics if output_count exceeds outputs.len().
