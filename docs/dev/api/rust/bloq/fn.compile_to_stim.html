pub fn compile_to_stim(graph: &BlockGraph, distance: u32) -> Result<String>
Expand description

Compile graph at distance and emit it as Stim circuit text.

Uses a fresh template cache. Equivalent to bloq_compile::compile followed by bloq_stim::emit_bloq_stim.

§Errors

Wraps compile::CompileError if distance is invalid or graph does not compile, and stim::StimEmissionError if the compiled program uses a node the static Stim backend cannot express (dynamic RepeatUntilSuccess or retry regions or unpinned quantum membership — use bloq_vm for dynamic execution).

§Examples

let stim_text = bloq::compile_to_stim(&bloq::graph::GalleryItem::CNOT.build(), 3)?;
assert!(stim_text.contains("QUBIT_COORDS"));
