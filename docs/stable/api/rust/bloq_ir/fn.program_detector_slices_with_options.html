Expand description

Compute detector-slice regions using explicit region choices.

ProgramSliceOptions::set_detectors_only omits logical-observable regions while retaining the same quantum tapes and detector regions. ProgramSliceOptions::set_physical_observables keeps logical regions but omits their known runtime sign folds. The default includes those folds and requires their complete record expressions to be affine.
