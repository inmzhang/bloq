pub fn run(args: impl IntoIterator<Item = OsString>) -> u8
Expand description

Run the CLI, with args a full argv whose first element is the executable name rather than an argument.

Public API: this is the one entry point behind both the bloq binary and the Python package’s bloq console script. It reports through the process stdout/stderr and returns a shell exit status instead of a Result — zero on success, including --help and a reader that closed the output pipe, one on command failure, and two on invalid arguments.
