Source
Expand description

Compile block graphs into physical circuit programs.

Pipeline: BlockGraph → [Bloq] → backend emission.

The compiler walks every block in a BlockGraph, resolves its signature and convention, generates per-block circuit templates, composes detectors and observables from stabilizer flows, and lowers the result into Bloq nodes suitable for backend emission.
